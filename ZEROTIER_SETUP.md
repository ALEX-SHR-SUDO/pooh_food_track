## Введение

### Проблема

Ваше приложение на Render.com не может подключиться к роутеру Cudy LT500, потому что роутер находится в локальной сети (например, `192.168.10.1`) и недоступен из интернета.

### Решение

Используем **ZeroTier VPN** - бесплатный сервис для создания виртуальных частных сетей. ZeroTier создает защищенный туннель между вашим роутером и приложением на Render.com **без необходимости арендовать VPS сервер**.

### Преимущества этого решения

✅ **100% Бесплатно** - ZeroTier Free tier (до 100 устройств)  
✅ **Без VPS** - не нужен отдельный сервер  
✅ **Безопасно** - End-to-end шифрование AES-256  
✅ **Просто** - настройка 10-15 минут  
✅ **Автоматический деплой** - через render.yaml  
✅ **Надежно** - роутер доступен 24/7 через ZeroTier  

### Стоимость

| Сервис | Стоимость |
|--------|-----------|
| ZeroTier | **$0** (бесплатно до 100 устройств) |
| VPS | **$0** (не требуется!) |
| Render.com | ~$7/месяц (2 сервиса на Starter plan) |
| **ИТОГО** | **~$7/месяц** |

## Архитектура решения

### Схема подключения

```
┌─────────────────────┐
│  Frontend (Vercel)  │
│   index.html        │
└──────────┬──────────┘
           │
           │ HTTP POST /api/send-verification-code
           ▼
┌─────────────────────────────────────┐
│  Render.com                         │
│  ┌───────────────────────────────┐  │
│  │ pooh-food-sms-backend         │  │
│  │ Node.js + Express             │  │
│  │ Port: 10000                   │  │
│  └─────────────┬─────────────────┘  │
│                │                     │
│                │ HTTP to pooh-zerotier-gateway.onrender.com
│                ▼                     │
│  ┌───────────────────────────────┐  │
│  │ pooh-zerotier-gateway         │  │
│  │ Docker (Alpine + ZeroTier)    │  │
│  │ Port: 10000                   │  │
│  │ ┌─────────────────────────┐   │  │
│  │ │ zerotier-one daemon     │   │  │
│  │ └──────────┬──────────────┘   │  │
│  │            │                   │  │
│  │            │ ZeroTier Network  │  │
│  │ ┌──────────▼──────────────┐   │  │
│  │ │ socat TCP proxy         │   │  │
│  │ │ Forwards to Router IP   │   │  │
│  │ └─────────────────────────┘   │  │
│  └───────────────────────────────┘  │
└─────────────────────────────────────┘
           │
           │ ZeroTier VPN Tunnel (encrypted)
           │ через my.zerotier.com cloud
           ▼
┌─────────────────────────┐
│  ZeroTier Cloud         │
│  (coordination server)  │
└──────────┬──────────────┘
           │
           │ ZeroTier VPN
           ▼
┌─────────────────────────┐
│  Cudy LT500 Router      │
│  Local: 192.168.10.1    │
│  ZeroTier: 192.168.192.x│
│  ┌────────────────────┐ │
│  │ ZeroTier Slave     │ │
│  │ Mode: Enabled      │ │
│  └────────────────────┘ │
│  ┌────────────────────┐ │
│  │ SMS Module (4G)    │ │
│  └────────────────────┘ │
└─────────────────────────┘
```

### Как это работает

1. **Frontend** отправляет запрос на Render.com backend
2. **Backend** делает HTTP запрос к `pooh-zerotier-gateway.onrender.com:10000`
3. **ZeroTier Gateway** (Docker контейнер на Render.com):
   - Подключен к ZeroTier сети
   - Получает запрос на порт 10000
   - Через `socat` перенаправляет на роутер через ZeroTier туннель
4. **Роутер Cudy LT500**:
   - Подключен к той же ZeroTier сети (ZeroTier Slave mode)
   - Получает запрос на порт 80
   - Обрабатывает через LuCI интерфейс
   - Отправляет SMS

## Шаг 1: Создание ZeroTier сети

### 1.1. Регистрация на ZeroTier

1. Перейдите на **https://my.zerotier.com/**
2. Нажмите **"Sign Up"** в правом верхнем углу
3. Выберите метод регистрации:
   - **Google Account** (рекомендуется)
   - **GitHub Account**
   - **Email + Password**
4. Подтвердите email (если выбрали регистрацию по email)
5. Войдите в аккаунт

### 1.2. Создание новой сети

1. На главной странице **https://my.zerotier.com/** нажмите **"Create A Network"**
2. Появится новая сеть с автоматически сгенерированным **Network ID** (16 символов)
3. **Сохраните Network ID** - он понадобится позже!
   - Пример: `a84ac5c10a1a2b3c`

### 1.3. Настройка сети

1. Кликните на созданную сеть, чтобы открыть настройки
2. **Измените имя сети** (опционально):
   - В поле **"Name"** введите: `POOH-Food-VPN`
3. **Настройте параметры сети**:

   **Settings (Основные настройки):**
   - ✅ **Access Control**: `Private` (оставить по умолчанию)
   - ✅ **IPv4 Auto-Assign**: Включено
   - ✅ **IPv6 Auto-Assign**: Можно отключить (не требуется)

   **IPv4 Auto-Assign (Настройка IP-адресов):**
   - Должен быть включен хотя бы один диапазон
   - Рекомендуется: `192.168.192.0/24` (по умолчанию)
   - Или можно добавить свой: `10.147.17.0/24`

   **Advanced (Расширенные):**
   - ✅ **Allow Managed**: Включено
   - ✅ **Allow Global**: Включено
   - ✅ **Allow Default Route**: Отключено (не требуется)

4. **Сохраните настройки** (автоматически сохраняется)

### 1.4. Важная информация о сети

На странице настроек сети вы увидите:

- **Network ID** - 16-значный идентификатор (сохраните!)
- **Members** - список подключенных устройств (пока пуст)
- **Managed Routes** - маршруты (можно оставить по умолчанию)

## Шаг 2: Настройка роутера Cudy LT500

### 2.1. Подключение к роутеру

1. **Включите роутер** и дождитесь загрузки (индикаторы засветятся)
2. **Подключитесь к роутеру**:
   - **По WiFi**: Сеть `Cudy-XXXX` (пароль на наклейке роутера)
   - **По Ethernet**: Кабелем в LAN порт
3. **Откройте браузер** и перейдите по адресу:
   - `http://192.168.10.1`
   - Или: `http://cudy.net`

### 2.2. Вход в веб-интерфейс

1. Введите данные для входа:
   - **Username**: `admin`
   - **Password**: `admin` (или ваш измененный пароль)
2. Нажмите **"Login"**

⚠️ **Важно**: Если пароль был изменен ранее, используйте ваш текущий пароль.

### 2.3. Активация ZeroTier Slave режима

Роутер Cudy LT500 поддерживает **ZeroTier Slave** режим - это означает, что он может подключаться к ZeroTier сети без необходимости установки дополнительного ПО.

1. В левом меню найдите **"Services"** или **"Сервисы"**
2. Найдите раздел **"ZeroTier"** или **"VPN"**
3. Включите **ZeroTier Slave** режим:
   - ☑️ **Enable ZeroTier**: Включить
   
4. **Введите параметры**:
   ```
   Network ID: [ваш Network ID из шага 1.2]
   Gateway: my.zerotier.com
   Port: 9993 (по умолчанию)
   ```

5. **Сохраните настройки** (кнопка **"Save"** или **"Apply"**)

6. **Перезагрузите роутер** (если требуется)

### 2.4. Получение ZeroTier ID роутера

После включения ZeroTier на роутере:

1. На странице ZeroTier настроек роутера найдите **"ZeroTier Address"** или **"Node ID"**
2. **Скопируйте этот ID** (10 символов, например: `a1b2c3d4e5`)
3. Этот ID понадобится для авторизации роутера в ZeroTier сети

💡 **Альтернативный способ**: ID роутера появится автоматически в списке **Members** на странице вашей ZeroTier сети через 1-2 минуты после включения ZeroTier на роутере.

### 2.5. Авторизация роутера в ZeroTier сети

1. Вернитесь на **https://my.zerotier.com/**
2. Откройте вашу сеть **POOH-Food-VPN**
3. Прокрутите вниз до раздела **"Members"**
4. Должен появиться новый член сети с:
   - **Address**: 10-значный Node ID роутера
   - **Name**: Пусто (можно заполнить: `Cudy-LT500-Router`)
   - **Auth**: Не авторизован (красный кружок)
5. **Авторизуйте роутер**:
   - ☑️ Установите галочку в колонке **"Auth"**
   - Кружок станет зеленым
6. **Назначьте имя** (опционально):
   - В поле **"Short Name"** введите: `Cudy-LT500`
   - В поле **"Description"** введите: `SMS Gateway Router`

### 2.6. Получение IP адреса роутера в ZeroTier

1. В разделе **"Members"** найдите ваш роутер
2. В колонке **"Managed IPs"** вы увидите назначенный IP адрес
3. **Сохраните этот IP** - он понадобится для настройки Render.com
   - Пример: `192.168.192.1` или `10.147.17.1`

💡 **Совет**: Вы можете назначить статический IP вручную:
- Кликните на IP адрес
- Введите желаемый IP из диапазона сети (например, `192.168.192.10`)
- Сохраните

## Шаг 3: Настройка Environment Variables в Render.com

### 3.1. Подготовка к деплою

1. **Смержите Pull Request** на GitHub (если еще не сделано):
   - Откройте ваш PR с ZeroTier изменениями
   - Нажмите **"Merge Pull Request"**
   - Подтвердите мерж
   - Убедитесь, что изменения попали в main/master ветку

2. **Откройте Render Dashboard**:
   - Перейдите на **https://dashboard.render.com/**
   - Войдите в аккаунт

### 3.2. Подключение репозитория (если еще не подключен)

1. На главной странице Render нажмите **"New +"** → **"Blueprint"**
2. Найдите ваш репозиторий **pooh_food_track**
3. Нажмите **"Connect"**
4. Render автоматически прочитает `render.yaml` и создаст 2 сервиса:
   - `pooh-zerotier-gateway` (Docker)
   - `pooh-food-sms-backend` (Node.js)

### 3.3. Настройка Environment Variables для ZeroTier Gateway

1. В Render Dashboard найдите сервис **"pooh-zerotier-gateway"**
2. Перейдите в **"Environment"** в левом меню
3. Добавьте следующие переменные:

   **ZEROTIER_NETWORK_ID**
   ```
   Key: ZEROTIER_NETWORK_ID
   Value: [ваш Network ID из шага 1.2]
   ```
   Пример: `a84ac5c10a1a2b3c`

   **ROUTER_ZEROTIER_IP**
   ```
   Key: ROUTER_ZEROTIER_IP
   Value: [IP роутера в ZeroTier из шага 2.6]
   ```
   Пример: `192.168.192.1`

   **PORT** (уже должен быть установлен в render.yaml)
   ```
   Key: PORT
   Value: 10000
   ```

4. Нажмите **"Save Changes"**

### 3.4. Настройка Environment Variables для Backend

1. В Render Dashboard найдите сервис **"pooh-food-sms-backend"**
2. Перейдите в **"Environment"** в левом меню
3. Добавьте/проверьте следующие переменные:

   **NODE_VERSION** (уже установлен)
   ```
   Key: NODE_VERSION
   Value: 25.6.0
   ```

   **PORT** (уже установлен)
   ```
   Key: PORT
   Value: 10000
   ```

   **ROUTER_IP** (должен указывать на ZeroTier Gateway)
   ```
   Key: ROUTER_IP
   Value: pooh-zerotier-gateway.onrender.com
   ```
   ⚠️ **Важно**: Используйте полный URL вашего ZeroTier Gateway сервиса!

   **ROUTER_PROTOCOL**
   ```
   Key: ROUTER_PROTOCOL
   Value: http
   ```

   **ROUTER_USER** (учетные данные роутера)
   ```
   Key: ROUTER_USER
   Value: admin
   ```

   **ROUTER_PASS** (учетные данные роутера)
   ```
   Key: ROUTER_PASS
   Value: [ваш пароль роутера]
   ```

4. Нажмите **"Save Changes"**

### 3.5. Авторизация ZeroTier Gateway в сети

После первого запуска Docker контейнер попытается подключиться к ZeroTier сети. Вам нужно его авторизовать:

1. **Дождитесь запуска** `pooh-zerotier-gateway` (1-2 минуты)
2. Вернитесь на **https://my.zerotier.com/**
3. Откройте вашу сеть **POOH-Food-VPN**
4. В разделе **"Members"** должен появиться новый член сети:
   - **Address**: 10-значный Node ID Docker контейнера
   - **Name**: Пусто
   - **Auth**: Не авторизован (красный кружок)
5. **Авторизуйте контейнер**:
   - ☑️ Установите галочку в колонке **"Auth"**
   - Кружок станет зеленым
6. **Назначьте имя** (опционально):
   - В поле **"Short Name"** введите: `Render-Gateway`
   - В поле **"Description"** введите: `Render.com ZeroTier Gateway`

💡 **Примечание**: После авторизации может потребоваться 1-2 минуты для установления соединения.

## Troubleshooting

### Проблема 1: ZeroTier Gateway не может подключиться к сети

**Симптомы**:
- В логах: `❌ ERROR: Failed to connect to ZeroTier network`
- Health check показывает `"connected": false`

**Решение**:

1. **Проверьте Network ID**:
   - Убедитесь, что `ZEROTIER_NETWORK_ID` правильный (16 символов)
   - Проверьте на наличие лишних пробелов

2. **Авторизуйте Gateway в ZeroTier**:
   - Откройте https://my.zerotier.com/
   - Перейдите в вашу сеть
   - В разделе "Members" найдите устройство Render Gateway
   - ☑️ Поставьте галочку "Auth"

3. **Перезапустите сервис**:
   - В Render Dashboard → `pooh-zerotier-gateway`
   - Нажмите "Manual Deploy" → "Deploy latest commit"

### Проблема 2: Router недоступен через ZeroTier

**Симптомы**:
- В логах Gateway: `⚠️ WARNING: Cannot reach router yet`
- Proxy работает, но роутер не отвечает

**Решение**:

1. **Проверьте ZeroTier на роутере**:
   - Войдите в веб-интерфейс роутера
   - Убедитесь, что ZeroTier включен
   - Проверьте, что Network ID правильный

2. **Авторизуйте роутер в ZeroTier**:
   - Откройте https://my.zerotier.com/
   - В разделе "Members" найдите роутер
   - ☑️ Поставьте галочку "Auth"

3. **Проверьте IP адрес роутера**:
   - На ZeroTier в "Members" посмотрите "Managed IPs" роутера
   - Убедитесь, что `ROUTER_ZEROTIER_IP` совпадает с IP в ZeroTier
   - Если не совпадает - обновите переменную в Render

4. **Проверьте маршруты ZeroTier**:
   - В настройках сети на my.zerotier.com
   - Убедитесь, что "Managed Routes" настроены правильно
   - По умолчанию должно быть достаточно

### Проблема 3: Backend не может подключиться к Gateway

**Симптомы**:
- Health check показывает ошибку
- В логах Backend: `✗ Router connection timeout (10s)`

**Решение**:

1. **Проверьте ROUTER_IP в Backend**:
   - Должен быть: `pooh-zerotier-gateway.onrender.com`
   - Убедитесь, что нет `http://` или `https://`
   - Проверьте имя сервиса в Render Dashboard

2. **Проверьте, что Gateway запущен**:
   - В Render Dashboard → `pooh-zerotier-gateway`
   - Статус должен быть "Live"
   - Если "Failed" - смотрите логи

3. **Проверьте порты**:
   - Gateway PORT = 10000
   - Backend PORT = 10000
   - Оба должны совпадать

### Проблема 4: SMS не отправляется

**Симптомы**:
- Backend подключается к роутеру
- Но SMS не приходит

**Решение**:

1. **Проверьте SIM карту**:
   - Есть ли деньги на счету
   - Есть ли SMS пакет
   - Работает ли сеть (4G индикатор)

2. **Проверьте учетные данные роутера**:
   - `ROUTER_USER` = `admin` (по умолчанию)
   - `ROUTER_PASS` = ваш пароль
   - Попробуйте войти вручную в веб-интерфейс роутера

3. **Проверьте формат номера**:
   - Должен быть международный формат: `+972501234567`
   - Без пробелов и дефисов
   - С кодом страны (+972 для Израиля)

4. **Проверьте SMS через веб-интерфейс роутера**:
   - Войдите в роутер
   - Network → GCOM SMS
   - Попробуйте отправить SMS вручную
   - Если не работает - проблема с роутером/SIM

### Проблема 5: Медленная работа через VPN

**Симптомы**:
- Запросы выполняются очень долго (>30 секунд)
- Таймауты

**Решение**:

1. **Проверьте качество интернета на роутере**:
   - Убедитесь, что сигнал 4G хороший (3-4 палочки)
   - Проверьте скорость интернета на роутере

2. **Увеличьте таймауты в коде** (опционально):
   - В `backend/cudy-lt500-api.js`
   - Найдите `timeout: 15000` и `timeout: 20000`
   - Увеличьте до 30000-40000 мс

3. **Проверьте нагрузку на ZeroTier сеть**:
   - Если подключено много устройств
   - Отключите неиспользуемые устройства

### Проблема 6: Render сервисы не запускаются

**Симптомы**:
- Статус "Build Failed" или "Deploy Failed"
- Ошибки в логах деплоя

**Решение**:

1. **Проверьте render.yaml**:
   - Убедитесь, что синтаксис правильный
   - Проверьте отступы (YAML чувствителен к отступам)

2. **Проверьте Dockerfile.zerotier**:
   - Убедитесь, что файл существует в корне репозитория
   - Проверьте синтаксис

3. **Проверьте Environment Variables**:
   - Все ли переменные установлены
   - Нет ли опечаток в названиях

4. **Смотрите логи деплоя**:
   - В Render Dashboard → Сервис → "Events"
   - Кликните на "Deploy" → "View Logs"
   - Найдите первую ошибку

### Проблема 7: "Auth?" галочка не появляется в ZeroTier

**Симптомы**:
- Устройство не появляется в "Members"
- Или появляется, но без галочки "Auth"

**Решение**:

1. **Подождите 2-3 минуты**:
   - ZeroTier может не сразу показать новое устройство

2. **Перезагрузите страницу my.zerotier.com**:
   - Нажмите F5 или Ctrl+R

3. **Проверьте логи устройства**:
   - Для Gateway - логи в Render Dashboard
   - Для роутера - статус ZeroTier в веб-интерфейсе

4. **Убедитесь, что Network ID правильный**:
   - На устройстве и в ZeroTier сети

## Альтернативные решения

Если ZeroTier по какой-то причине не подходит, вот альтернативные VPN решения:

### Вариант 1: Tailscale (рекомендуется как альтернатива)

**Преимущества**:
- ✅ Проще в настройке чем ZeroTier
- ✅ Лучший UI
- ✅ 100 устройств бесплатно

**Недостатки**:
- ❌ Cudy LT500 не поддерживает Tailscale "из коробки"
- ❌ Требует установки клиента на роутер (если поддерживается)

**Сравнение с ZeroTier**:
| Критерий | ZeroTier | Tailscale |
|----------|----------|-----------|
| Бесплатных устройств | 100 | 100 |
| Поддержка на LT500 | ✅ Да (Slave mode) | ❌ Нет |
| Простота настройки | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| Скорость | Высокая | Очень высокая |

### Вариант 2: WireGuard через бесплатный VPN

**Как работает**:
1. Настройте WireGuard на роутере (если поддерживается)
2. Используйте бесплатный VPN сервис для координации
3. Подключите Render через WireGuard клиент

**Преимущества**:
- ✅ Очень быстрый протокол
- ✅ Низкие задержки

**Недостатки**:
- ❌ Сложнее настроить
- ❌ Cudy LT500 может не поддерживать WireGuard
- ❌ Требуется ручная настройка ключей

### Вариант 3: OpenVPN через ProtonVPN Free

**Как работает**:
1. Создайте бесплатный аккаунт ProtonVPN
2. Настройте OpenVPN на роутере
3. Подключите через ProtonVPN

**Преимущества**:
- ✅ Популярный протокол
- ✅ ProtonVPN бесплатный

**Недостатки**:
- ❌ ProtonVPN Free имеет ограничения скорости
- ❌ Сложная настройка
- ❌ Может быть медленным

### Вариант 4: CloudFlare Tunnel

**Как работает**:
1. Установите `cloudflared` на роутер (если поддерживается)
2. Создайте туннель через CloudFlare
3. Подключитесь к роутеру через туннель

**Преимущества**:
- ✅ 100% бесплатно
- ✅ Быстрый и надежный
- ✅ Отличная документация CloudFlare

**Недостатки**:
- ❌ Cudy LT500 не поддерживает `cloudflared` "из коробки"
- ❌ Требует установки ПО на роутер
- ❌ Более сложная настройка

### Рекомендация

Для Cudy LT500 **ZeroTier** - это лучший вариант, потому что:
1. ✅ Роутер поддерживает ZeroTier Slave mode "из коробки"
2. ✅ Не требуется установка дополнительного ПО
3. ✅ Простая настройка (10-15 минут)
4. ✅ Стабильная работа
5. ✅ 100% бесплатно

## FAQ

### Q: Сколько это стоит?

**A**: ZeroTier бесплатно для до 100 устройств. Render.com стоит ~$7/месяц за 2 сервиса. **Итого: $7/месяц**.

### Q: Нужно ли открывать порты на роутере?

**A**: **Нет!** ZeroTier работает через исходящие соединения. Не нужно настраивать порт форвардинг или открывать порты.

### Q: Безопасно ли это?

**A**: **Да!** ZeroTier использует end-to-end шифрование AES-256. Соединение между Render и роутером полностью зашифровано.

### Q: Что если роутер перезагрузится?

**A**: ZeroTier автоматически переподключится после перезагрузки роутера. Никаких действий не требуется.

### Q: Можно ли использовать это для других сервисов?

**A**: **Да!** Вы можете подключить к ZeroTier сети любые устройства: компьютеры, телефоны, другие сервера.

### Q: Как удалить устройство из ZeroTier сети?

**A**: На my.zerotier.com → Ваша сеть → Members → Нажмите на устройство → "Delete".

### Q: Что делать, если забыл Network ID?

**A**: Войдите на https://my.zerotier.com/ и посмотрите ID своей сети на главной странице.

### Q: Можно ли использовать с другими роутерами?

**A**: **Да**, если роутер поддерживает ZeroTier или на него можно установить ZeroTier клиент.

### Q: Влияет ли ZeroTier на скорость?

**A**: Минимально. Добавляется ~20-50ms задержки. Для SMS это незаметно.

### Q: Сколько SMS можно отправить?

**A**: Ограничение только от SIM карты и тарифа. Сама система не ограничивает количество.

### Q: Работает ли это с другими облачными платформами?

**A**: **Да!** Вы можете использовать это решение с AWS, Google Cloud, Azure, Heroku и т.д.

### Q: Нужно ли платить за ZeroTier после 100 устройств?

**A**: Да, но для этого проекта достаточно бесплатного плана (роутер + Gateway = 2 устройства).

## Безопасность

### Лучшие практики безопасности

1. **Измените пароль роутера**:
   - Не используйте стандартный `admin:admin`
   - Используйте сложный пароль (12+ символов)

2. **Используйте приватные ZeroTier сети**:
   - Всегда держите "Access Control" = "Private"
   - Авторизуйте только доверенные устройства

3. **Регулярно проверяйте Members**:
   - Удаляйте неиспользуемые устройства
   - Мониторьте "Last Seen" - должны быть только ваши устройства

4. **Храните секреты в Environment Variables**:
   - Никогда не коммитьте пароли в Git
   - Используйте Render Environment Variables

5. **Включите 2FA на важных аккаунтах**:
   - GitHub
   - Render.com
   - ZeroTier

6. **Мониторьте логи**:
   - Регулярно проверяйте логи Render
   - Ищите подозрительную активность

### Что защищает ZeroTier

✅ **Шифрование трафика** - AES-256 end-to-end  
✅ **Аутентификация устройств** - только авторизованные устройства  
✅ **Приватная сеть** - не доступна из интернета  
✅ **Изоляция** - устройства видят только друг друга в сети  

### Что НЕ защищает ZeroTier

❌ **Безопасность роутера** - нужно использовать сильный пароль  
❌ **Безопасность приложения** - нужна валидация данных  
❌ **DDoS атаки** - используйте CloudFlare для защиты frontend  

### Рекомендации по безопасности для production

1. **Rate limiting**:
   - Ограничьте количество SMS в минуту/час
   - Используйте Redis для хранения счетчиков

2. **Мониторинг**:
   - Настройте алерты в Render для ошибок
   - Используйте Sentry для отслеживания ошибок

3. **Backup**:
   - Регулярно делайте backup конфигурации роутера
   - Сохраните Network ID и важные настройки

4. **Updates**:
   - Обновляйте прошивку роутера
   - Обновляйте Node.js пакеты (`npm update`)
